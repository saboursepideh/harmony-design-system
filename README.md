# Harmony — Orchestry design system

Live playground: https://saboursepideh.github.io/harmony-design-system/
Reference docs: https://saboursepideh.github.io/harmony-design-system/docs.html

- 237 design tokens (`orchestry-tokens.json` → `orchestry-tokens.css`, Figma variables, `orchestry-mantine-theme.ts`)
- 30 live components with rules, code and tokens
- AI Studio: describe a component and it is built only from Harmony tokens and parts, with its rules written and contrast checked
- `harmony.rules.md`: the rules file read by people and AI

Designed by Sara Sabour.
